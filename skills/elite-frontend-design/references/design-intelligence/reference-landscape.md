# Reference Landscape

This registry is a **breadth map for reference selection**, not a library of proven design rules.

It exists to help `design-intelligence` choose the right teachers before a deep audit. Names in this file may be strong references, but unless a dedicated audited profile exists under `sites/`, their specific mechanisms remain unverified.

## Candidate, Not Evidence

Treat entries in this registry as **candidates** by default.

- A candidate can inspire a shortlist.
- A candidate can establish that a market/archetype exists.
- A candidate can help detect common visual grammar.
- A candidate **cannot** justify a source/runtime/performance/responsive claim.
- A candidate **cannot** promote a site-specific mechanism into general guidance without audit or independent corroboration.

## 6. template commodity

Use this landscape mainly to understand **market defaults** and trigger the Template Archetype Firewall.

Audited template reference:

- NovaOS (Framer template) - **audited**
- Powder (Framer template) - **audited**
- Nudge Folio (Framer template) - **audited**

Common commodity archetypes observed in modern template ecosystems:

### Linear-dark SaaS

- black/charcoal shell;
- small mono labels;
- purple/blue glow;
- floating dashboard cards;
- subtle grid/noise background;
- rounded dark CTA/buttons.

### AI glowing-orb startup

- centered hero;
- gradient text;
- glowing orb/mesh as brand substitute;
- pill badge above headline;
- large "Get started" + secondary demo CTA;
- generic bento below.

### Framer/Webflow B2B SaaS

- strong centered first fold;
- logo strip;
- bento feature matrix;
- alternating image/text sections;
- testimonial cards;
- pricing/FAQ/CTA close.

### Bento UI product site

- every capability represented as a rounded tile;
- mixed tile sizes create visual rhythm;
- charts/code/avatars inserted as decorative proof;
- risk: information hierarchy is replaced by masonry composition.

### Developer-terminal aesthetic

- mono-heavy typography;
- command prompt/code panels;
- green/purple syntax-like accents;
- grid/dot background;
- risk: fake code or terminal chrome with no relationship to the actual product.

### YC/minimal startup

- concise centered hero;
- one screenshot;
- logos/testimonials;
- short feature list;
- simple pricing and FAQ;
- useful for speed and clarity, weak as a distinctive brand system unless the product itself carries identity.
- VoxAI (Framer template) - **audited**


## Template Convergence Risk

Template grammar becomes risky when a new design accumulates several conventions from the same archetype without a product-specific reason.

Use this heuristic:

1. Name the closest commodity archetype.
2. Count recognizable conventions inherited from it.
3. At four or more, require a structural differentiator.
4. Verify the differentiator survives mobile and real content.
5. If removing brand color/logo makes the page indistinguishable from the template archetype, the design is still converged.

Valid differentiators include a distinct information model, proof mechanism, composition system, typographic role structure, interaction grammar, responsive transformation, or signature media behavior.

Cosmetic substitutions alone do not pass.

## Breadth-to-Depth Usage

Use this registry in this order:

**landscape -> candidate set -> archetype comparison -> 1-3 source shortlist -> deep audit -> site profile -> selective pattern promotion**

Do not preload this whole file when a specific audited profile already matches the brief. Its purpose is reference discovery and anti-template awareness, not to mix every admired website into one design.
