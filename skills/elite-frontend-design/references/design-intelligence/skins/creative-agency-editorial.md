# Baseline Skin: Creative Agency Editorial

Refokus audited evidence anchor: ../sites/refokus.com.md
Nudge Folio audited template anchor: ../sites/nudge-folio.framer.website.md

This skin serves creative studios, agencies, independent designers, portfolios, and premium B2B storytelling where work, process, art direction, and editorial pacing carry the sale.

Refokus contributes high-ambition agency evidence: one signature stage, bounded immersive rendering, motion-as-focus, editorial case studies, project color worlds, and Responsive Brand Payload.

Nudge Folio contributes a whole-site lower-cost template baseline: expressive typography roles, full portfolio route architecture, Reflective Case Study Arc, Persistent Context Rail, responsive release of sticky geometry, and Experimental Surface Isolation.

Do not average the two into one visual style. Route ambition to the brief and execution capability.

## Use when

Use for:
- creative agencies and studios;
- product/brand designers;
- independent portfolios;
- premium service businesses where case studies matter;
- campaign/experience makers;
- editorial B2B storytelling;
- lower-capability execution that needs a coherent portfolio scaffold.

Avoid using this as the primary skin for dense dashboards, developer APIs, transactional ecommerce, or highly regulated enterprise information products.

## Deterministic Design Scaffold

Allocate ambition asymmetrically:
- one identity-bearing hero/signature move;
- one coherent quiet shell for navigation, reading, and support routes;
- rich work proof;
- calmer supporting routes;
- optional experimental surface isolated from required tasks.

A strong portfolio should still work if the expensive signature interaction is removed.

## Token Scaffold

- global shell: neutral/light, neutral/dark, or brand-tinted, but keep one stable shell grammar;
- project surfaces may own distinct palettes;
- display role: expressive and high-contrast;
- body/narrative role: quiet and highly readable;
- metadata role: compact sans or mono;
- optional annotation role: handwritten/italic/alternate face only when it has a job;
- editorial media radius: 0-12px by default;
- controls: 8-16px;
- large display: roughly 64-120px desktop, reduced deliberately on mobile;
- extreme 120px+ type is allowed only when layout can absorb it;
- body: roughly 16-20px;
- container: roughly 1200-1360px for conventional routes;
- section gap: roughly 112-176px desktop;
- avoid universal card containers.

Nudge demonstrates that four typography roles can coexist when each role is semantically owned. Refokus demonstrates that expressive type can coexist with an immersive signature stage.

## Composition Grammar

### Home / landing

Reliable sequence:
1. identity or positioning;
2. one personality/signature cue;
3. selected proof/work;
4. case-study/project progression;
5. optional process/capabilities;
6. conversion;
7. contact/footer.

Do not summarize every detail route on home.

### Work index

Use a fast scan:
- project name;
- short context;
- role/year/category only when useful;
- strong media;
- obvious route into the case study.

Do not force every project into identical rounded cards.

### Case-study detail

Prefer the Reflective Case Study Arc:
- real problem/context;
- approach/intervention;
- what happened;
- what changed;
- constraints/tradeoffs;
- what I would do differently;
- what I learned;
- next project or conversion.

Use only sections supported by real evidence.

### About

Use biography + working principles + selected proof.
A Persistent Context Rail is optional when the route is long enough to benefit from local orientation.

### Services

Separate:
- capabilities;
- process;
- evidence;
- FAQ/objections;
- conversion.

Do not restyle a portfolio project grid and call it a services page.

### Journal / insights

Use editorial typography and article-specific hierarchy.
Keep article reading calmer than the marketing shell.

### Contact

Reduce complexity.
A portfolio earns conversion through proof; contact should not repeat the entire sales page.

## Reflective Case Study Arc

Use when case studies need to prove design judgment, not only visuals.

Preferred arc:

problem/context -> intervention -> observable result -> constraints/tradeoffs -> reflection/learning

Optional extensions:
- role/team/timeline;
- research evidence;
- before/after;
- what I would do differently;
- next-project handoff.

Never fabricate outcomes, metrics, research, constraints, or retrospective insight.

## Persistent Context Rail

Optional for:
- long case studies;
- about/story pages;
- articles;
- process documentation.

May contain:
- local section navigation;
- project metadata;
- article date/category/summary;
- role/team/timeline;
- progress/orientation.

Rules:
- sticky/fixed context must reduce cognitive reset;
- it must not cover the main reading column;
- mobile may narrow, release, or inline the rail;
- preserve reading order and touch/keyboard access.

## Full-Viewport Project Stack

Optional desktop signature.

A project can own a viewport-scale sticky stage when:
- each project meaningfully differs;
- repeated geometry improves comparison;
- the work can carry the screen;
- scroll length remains reasonable.

Release this geometry on mobile when it becomes oppressive.

Nudge is evidence for the desktop sticky-project mechanism; it is not a reason to copy exact panel dimensions or project colors.

## Experimental Surface Isolation

Optional portfolio/studio route.

Use a playground/lab/experiments route when personality benefits from:
- drag;
- spatial collage;
- freeform layout;
- cursor play;
- unusual input grammar;
- less commercial content.

Rules:
- keep conventional navigation/escape available;
- do not require the experiment to understand the portfolio;
- do not make contact or case-study proof depend on it;
- preserve touch usability if kept on mobile;
- bound experimental interaction to that surface.

Identity overflow is useful only when usability spillover is prevented.

## One Signature Stage

Refokus remains the high-ambition anchor for this pattern.

A signature stage may be:
- bounded WebGL/3D;
- a strong hero composition;
- a sticky project sequence;
- a single authored motion transition;
- an experimental playground.

Do not distribute equal spectacle across every route.

## Skin Lock

Lock:
- global shell grammar;
- typography roles;
- editorial spacing rhythm;
- media framing rules;
- control language;
- case-study narrative standard;
- navigation hierarchy;
- motion ownership;
- responsive identity priorities.

## Controlled Mutation

May mutate:
- project palettes;
- hero composition;
- signature interaction;
- media subject;
- typography families;
- case-study ordering where content demands it;
- whether sticky/context/playground mechanisms are used;
- light vs dark shell.

Must mutate away from audited identities:
- Refokus exact 3D object, palette, typography, copy, project worlds;
- Nudge exact Flux/handwritten/mono combination;
- Nudge project names, stories, captions, dates, layout dimensions;
- template/vendor controls.

## Responsive Contract

Preserve the Responsive Brand Payload:
- typography role contrast;
- project ordering;
- recognizable media treatment;
- proof narrative;
- one identity-bearing cue.

Then adapt:
- reduce display scale;
- collapse grids;
- release full-viewport sticky project stages;
- resize or inline context rails;
- remove pointer-only effects;
- keep playground touch-safe or simplify it;
- keep document-level horizontal overflow at zero unless an intentional bounded internal surface owns it.

Do not replace a distinctive portfolio with a generic stacked card template on mobile.

## Motion Language

Priority:
1. navigation/input feedback;
2. project-state changes;
3. one signature transition;
4. local sticky continuity;
5. optional ambient motion.

Avoid:
- universal fade-up;
- continuous parallax everywhere;
- custom cursor as required navigation;
- drag interaction on task routes;
- animation that hides case-study reading.

## Anti-Template Guard

High-risk portfolio-template bundle:
- huge grotesk name;
- handwritten doodle font;
- tiny mono metadata;
- sticky project cards;
- colored project backgrounds;
- cursor follower;
- playground collage;
- oversized Let's Talk footer.

Using several together without product/person-specific meaning creates template convergence.

Require structural differentiation in at least one:
- project narrative;
- information architecture;
- type-role system;
- proof mechanism;
- signature interaction;
- media art direction;
- responsive transformation.

Changing names/colors only does not count.

## QA Rubric

Pass only if:
- the portfolio has a coherent global shell;
- project worlds can vary without visual fragmentation;
- typography roles are clear;
- case studies prove judgment, not just final screens;
- Reflective Case Study Arc stays truthful;
- Persistent Context Rail helps orientation when used;
- Experimental Surface Isolation keeps playful input out of required tasks;
- one signature stage earns its complexity;
- mobile preserves identity while releasing desktop-only geometry;
- body/article text remains readable;
- document-level overflow is controlled;
- template/vendor identity is excluded;
- the result remains distinguishable after removing exact Refokus/Nudge colors, fonts, assets, copy, and interactions.
