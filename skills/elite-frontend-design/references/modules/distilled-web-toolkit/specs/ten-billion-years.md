## Composition Grammar
- Entry gate -> weighted chapters -> sparse event peaks -> final payoff -> delayed coda/replay.
- One authored story progress owns world, DOM, HUD, FX and audio state.

## Interaction Grammar
- Scroll = story time.
- Pointer = camera/world response.
- Tap/click = bounded shock/event response.
- Audio is opt-in and nonessential to comprehension.

## Responsive / Performance
- Reduce HUD and renderer quality before reducing semantic story coverage.
- Reduced motion is a different rendering mode, not simply faster animation.

## Toolkit Patterns
`cosmos-prompt-compile`, `cosmos-parameter-matrix`, `cosmos-event-peaks`, `cosmos-weighted-timeline`, `cosmos-shared-progress`, `cosmos-one-world`, `cosmos-two-layer`, `cosmos-adaptive-budget`, `cosmos-procedural-score`, `cosmos-payoff-first`.
